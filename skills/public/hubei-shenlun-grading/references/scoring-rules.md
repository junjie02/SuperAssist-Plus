# 主流程可见的评分控制规则

本文件只供主 Agent 核验题型分派和程序状态。主 Agent 不得据此制定采分点、拆分分值或计算终分。完整量化细则已固定在各题型专家 Agent 的 `system.md` 中。

## 题型映射

| type | 中文题型 | 固定专家 Agent | 双评分差阈值 |
| --- | --- | --- | --- |
| `summary` | 归纳概括 | `shenlun-summary-grader` | 满分的 20% |
| `analysis` | 综合分析 | `shenlun-analysis-grader` | 满分的 20% |
| `countermeasure` | 提出对策 | `shenlun-countermeasure-grader` | 满分的 20% |
| `document` | 贯彻执行/公文写作 | `shenlun-document-grader` | 满分的 20% |
| `essay` | 文章论述/大作文 | `shenlun-essay-grader` | 满分的 15% |

## 程序裁决

1. 同题型专家 A、B 独立评分，互相不可见。
2. A/B 分差不超过对应阈值时，程序取两者平均分。
3. A/B 分差超过阈值时，程序启动同题型专家 C 独立评分。
4. 三个分数中存在不超过阈值的组合时，程序选择分差最小的一组并取平均分；最近组合并列时进入仲裁，避免程序任意选择。
5. 三组分差均超过阈值时进入仲裁。仲裁专家读取 A/B/C 的完整评分依据并给出终裁分，程序采用该终裁分，不再取两份平均。
6. 三评和仲裁只能由评分程序触发，主 Agent不得重跑评分、选分或改分。

## 评分依据所有权

- 有官方答案或官方评分参考：主 Agent只逐字转录；专家结合题干、材料和官方原文判断采分点及命中情况。
- 无官方评分参考：A/B/C 各自独立推导 `derived_scoring_points`，不得共享或继承另一评分员的采分点。
- 答案字数由评分程序从“考生答案逐字转写”段落统计非空白字符后传给专家；专家不得自行估算，结果中的 `word_count` 以程序值为准。
- OCR 无法辨认内容不得作有利推断；扫描范围外内容不计分。
- 专家结果必须包含分项得分、扣分项、固定公式、命中点、遗漏点和修改建议。主 Agent只读取持久化结果并向用户展示。

## 批次级质检边界

官方披露的 3% 已阅答卷回抽重评属于跨答卷质量控制，不属于单份五题答卷的评分链路。本工具当前不在单卷内随机追加自评；后续应由独立批次质检任务按累计答卷抽样执行。
